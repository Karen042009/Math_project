# ProbSpace

Մաթեմատիկական ինտերակտիվ և ամբողջական կրթական հարթակ՝ երկու հիմնական ուղղությամբ․ **Հավանականություն** (Probability Theory) և **Ինտեգրալային ու դիֆերենցիալ հաշիվ** (Calculus & Integrals), ինչպես նաև լրացուցիչ թեմա տվյալների պաշտպանության և մոդուլային թվաբանության վերաբերյալ։

---

## 🚀 Հիմնական բաժինները և հնարավորությունները

1. **Տեսություն (Theory Encyclopedia)**
   - **Հավանականություն (11 գլուխ, 42 ենթաբաժին)**՝ պատմություն, պատահական փորձեր, ելքերի տարածություն, դասական սահմանում, աքսիոմներ, կոմբինատորիկա (տեղափոխություններ, կարգավորություններ, զուգորդություններ), գումարման թեորեմ, ներառման-բացառման սկզբունք, պայմանական հավանականություն, անկախություն, լրիվ հավանականություն, Բայեսի բանաձև, պատահական մեծություններ (դիսկրետ և անընդհատ), մաթ. սպասում, դիսպերսիա, ստանդարտ շեղում, բաշխումներ (Բինոմ, Պուասոն, Նորմալ), մեծ թվերի օրենք, կենտրոնական սահմանային թեորեմ, երկրաչափական հավանականություն, Մոնտե Կառլոյի սկզբունք և սիմուլյացիաների տեսություն։
   - **Ինտեգրալ (11 գլուխ, 40+ ենթաբաժին)**՝ պատմություն, ֆունկցիաներ և սահմաններ, ածանցյալի իմաստ և կանոններ, նախնական ֆունկցիա, անորոշ ինտեգրալ, աղյուսակ, փոփոխականի փոխարինում, մասերով ինտեգրում, Ռիմանի գումարներ և որոշյալ ինտեգրալ, Նյուտոն-Լայբնիցի թեորեմ, մակերեսներ կորի տակ և կորերի միջև, ծավալներ լայնական հատույթներով, սկավառակներով և օղակներով, գլանի, կոնի և գնդի ծավալների դուրսբերում, կինեմատիկա (դիրք, արագություն, արագացում, տեղաշարժ, ճանապարհ), թվային և Մոնտե Կառլո ինտեգրում։
   - **Լրացուցիչ թեմա**՝ Ինչպես է հանրահաշիվը պաշտպանում տվյալները (մոդուլային թվաբանություն, ծածկագրություն, RSA)։

2. **Խնդիրներ (Practice Arena)**
   - 43+ հիմնական պատրաստի խնդիրներ և 50+ պարամետրական գեներացվող խնդիրներ երկու ուղղություններով։
   - Համատեղ զտիչներ՝ **ուղղություն + թեմա + բարդություն (4 մակարդակ) + լուծվածության կարգավիճակ**։
   - Խելացի քայլային օգնական․
     - 1-ին սխալ՝ ուղղորդող խորհուրդ,
     - 2-րդ սխալ՝ բանաձև կամ հուշում,
     - 3-րդ սխալ՝ ամբողջական մանրամասն լուծում։
   - «Անցնել տեսությանը» կոճակը բացում է համապատասխան ուղղությունն ու ենթաբաժինը։

3. **Լաբորատորիա և Հաշվիչներ (The Lab)**
   - **Սովորական հաշվիչ**՝ անվտանգ AST մաթեմատիկական parser-ով (առանց `eval` կամ `new Function`)։
   - **Հավանականություն**՝ Բեռնուլի, Բայես, զուգորդություններ, տեղափոխություններ, Պուասոն, Նորմալ բաշխում (ճշգրտված $\Phi(z)$ Z-աղյուսակ, $\Phi(1) \approx 0.841345$), Վեննի դիագրամներ (2 և 3 բազմություններ), հավանականության ծառեր։
   - **Ածանցյալ և ինտեգրալ**՝ ածանցյալ $x_0$ կետում և շոշափողի գրաֆիկ, անորոշ ինտեգրալ $F(x)+C$ ստուգմամբ, որոշյալ ինտեգրալ (Սիմպսոն, սեղան, միջնակետ, Մոնտե Կառլո) խզումների / առանձնահատկությունների նախազգուշացմամբ։
   - **Մակերես**՝ երկրաչափական մակերես կորի և առանցքի միջև ($\int |f(x)|dx$) և երկու կորերի միջև ($\int |f(x)-g(x)|dx$), արմատների և հատման կետերի որոնմամբ։
   - **Ծավալ**՝ սկավառակներ, օղակներ, լայնական հատույթներ և պատրաստի երկրաչափական մարմիններ (գլան, կոն, գունդ)։
   - **Շարժում**՝ $s(t) \to v(t), a(t)$, տեղաշարժ $\Delta s = \int v(t)dt$ և լրիվ ճանապարհ $L = \int |v(t)|dt$։

4. **Ինտերակտիվ Սիմուլյացիաներ**
   - **Մոնտե Կառլո ինտեգրում**՝ երկու ռեժիմ (Hit-or-Miss և Sample Mean), ճշգրտված դինամիկ սահմաններ, բացասական/նշանափոխ ֆունկցիաների աջակցություն, զուգամիտության գրաֆիկ, ստանդարտ սխալի հաշվարկ։
   - **Գալտոնի տախտակ**, **Մոնտի Հոլլ**, **Բյուֆոնի ասեղ**, **Մետաղադրամ**, **Զառեր**։

## 🔒 Gemini API-ի կարգավորում և անվտանգություն

- Նախագծի հանրային կոդում կամ HTML-ում **գաղտնի API բանալիներ ներառված չեն**։
- Տեղային բոլոր հնարավորությունները (գեներատոր, պատասխանների ստուգում, քայլային լուծումներ) լիարժեք գործում են **անցանց (offline)**՝ առանց որևէ բանալու։
- Եթե ցանկանում եք ակտիվացնել Gemini API-ի հեռավար մոդելը, այն կարող եք անվտանգ պահպանել ձեր սեփական դիտարկչի `localStorage`-ում․

  Բացեք դիտարկիչի Developer Console-ը (F12) և կատարեք․
  ```javascript
  localStorage.setItem('probspace_gemini_api_key', 'ՁԵՐ_GEMINI_API_ԲԱՆԱԼԻՆ');
  ```
- **Կարևոր անվտանգության ծանուցում**․ Եթե երբևէ նախկինում հրապարակել կամ կիսվել եք որևէ API բանալիով, պարտադիր չեղարկեք (Revoke) այն [Google AI Studio](https://aistudio.google.com/app/apikey) հարթակում՝ որպես հաշվի մակարդակի առանձին անվտանգության գործողություն։

## Ստուգումներ և հաշվարկի սահմաններ

```bash
node tests/regression.cjs
node tests/math-renderer.cjs
python3 -B tests/theory_diagrams.py
```

Անորոշ ինտեգրալի լուծիչը աջակցում է բազմանդամների գումարներին, հաստատուն արտադրիչներին, գծային արգումենտով աստիճանային, sin, cos և exp ֆունկցիաներին, ինչպես նաև պարզ լոգարիթմական նախնականներին։ Այլ արտահայտությունների համար օգտագործեք որոշյալ ինտեգրալի թվային ռեժիմը։

Գեներացված խնդիրների եզակի խմբաքանակը պահվում է դիտարկչում։ V1/V2 առաջադիմությունը չի վերագրվում V3 խնդիրներին, քանի որ հին տարբերակներում ID-ները կարող էին համապատասխանել այլ առաջադրանքների։ Նախկին տվյալները մնում են տեղային պահոցում։

Գլխավոր էջի ինտեգրման պատկերը սխեմատիկ է։ Իրական պատահական ընտրանքով հաշվարկը հասանելի է «Սկսել փորձը» կոճակով։

Տեսության մեջ կա 24 գլուխ և 70 ենթաբաժին՝ երեք լեզվով։ Ինտեգրալի հատկությունների ու կիրառման սահմանների նոր նյութը գտնվում է 5-րդ գլխում, իսկ Մոնտե Կառլոյի ստանդարտ սխալի և մոտավոր վստահության միջակայքի բացատրությունը՝ 11-րդ գլխում։ Հավանականության սահմանային թեորեմների լրացումները պահվում են `build_data_src/probability_refinements.py`-ում։

Տեսության էջը սկզբում ստեղծում է բովանդակությունն ու վերնագրերը, ապա նյութն ու բանաձևերը բեռնում է կարդալուն զուգընթաց։ MathJax-ի մշակումը կատարվում է հերթով՝ մեկ հատված յուրաքանչյուր կադրում։ Կատարված չափումների պայմաններն ու արդյունքները՝ `PERF.md`-ում։

Երկար բանաձևերի ինքնաշխատ տողադարձումն ապահովում է MathJax 4-ը։ Տեսության գծագրերի վերնագրերն ու բացատրությունները SVG-ից դուրս են, որպեսզի բնական տողադարձվեն։ Գծագրերի եռալեզու սկզբնաղբյուրը՝ `build_data_src/theory_diagrams.py`։
